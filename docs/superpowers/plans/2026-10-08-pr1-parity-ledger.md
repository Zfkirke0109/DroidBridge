## Dependency audit

- `cargo-audit` found [RUSTSEC-2026-0285](https://rustsec.org/advisories/RUSTSEC-2026-0285) in pinned `rustls` 0.23.35. The workspace now pins patched 0.23.45, and a fresh audit of its 207 lockfile dependencies found no advisory.
- An audit of the Windows deployment CLI cache (`wrangler` 4.148.0 → `miniflare` → `sharp` 0.35.4) reports [GHSA-wq5f-xc86-pv6w](https://github.com/advisories/GHSA-wq5f-xc86-pv6w). The advisory's possible code execution requires SVG decoding by `sharp` on glibc-based Linux. This run uses Wrangler on Windows only to bundle/deploy plain JavaScript, does not decode SVGs, and does not package `miniflare` or `sharp` into the Worker. The currently published latest Wrangler is 4.148.0; re-audit before any Linux-based deployment workflow is added.
